# CHANGELOG for MyFatoorah Bagisto Module

## **v2.1.2(23th of Aug, 2024)** - Release

MyFatoorah payment gateway module for Bagisto, allowing merchants to accept payments through MyFatoorah.

The module supports multiple payment methods, including credit cards, debit cards, Google Pay and Apple Pay, and allows customers to pay in multiple currencies.

## Features:
* [feature] - Admin can configure MyFatoorah API keys and payment methods.
* [feature] - Admin can enable/disable payment methods.
* [feature] - Admin can set payment method titles and descriptions.
* [feature] - Admin can view all transactions and payment history.
* [feature] - Customers can pay using MyFatoorah payment gateway.
* [feature] - Customers can view payment history and transaction details.
* [feature] - Payment gateway supports 3D Secure 2.0 for enhanced security.
* [feature] - Payment gateway supports multiple currencies.
